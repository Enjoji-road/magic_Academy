# 魔法学校：録音素材の効果音試作

作業日：2026-10-21。対象：`academy-preview.html`、`fire-studio.html`、`earth-studio.html`。BGMは使用していません。

## 採用の位置づけと、試聴できた範囲

**録音素材8種をゲーム操作に仮採用しました。聴覚による比較は未了です。**

公式サイトのプレビューを14候補でクリックし、正規ダウンロードの操作を行いました。ただし、この実行環境では出力された音を耳で確認できません。クリック操作の成功を、音が聞こえたことや聴感を評価したことの代用にはしていません。

取得したファイルはffmpegでデコードし、実測の長さ・ピーク・無重み付けの平均レベルを比較しました。「自然に聞こえた」「繰り返しても疲れなかった」といった聴取評価は行っていません。音質・素材の組み合わせ・実機音量の最終決定には、人によるプレイ中の聴取が必要です。

提供元は、すべて[効果音ラボ](https://soundeffect-lab.info/)です。

- [利用規約](https://soundeffect-lab.info/agreement/)：商用作品での使用・改変を認めています。外部音源への直リンク、素材集や効果音紹介のみを目的とした再配布などは禁止です。
- [FAQ](https://soundeffect-lab.info/faq/)：ゲーム・アプリの操作音としての組み込みと、音源ファイルが見える形でのGitHub公開を認める項目を確認しました。素材自体を自由利用のプロジェクトライセンスへ変更するものではありません。
- ゲームから参照するのは同じリポジトリの `assets/studio-sfx/` だけです。素材の単独試聴アプリ・音だけの紹介ページ・外部MP3への再生リンクは設けていません。
- クレジットは設定画面と本資料に記録しました。素材単体の転載・素材集としての利用は、このゲームの利用条件とは別です。

確認日：2026-10-21。実際に素材を再利用する際は、提供元の規約を確認してください。

## 加工と音量

1. 上表の短い区間を取り出し、モノラル・44.1kHz・96kbpsのMP3に変換。
2. 区間の変換前ピークを基準に、目標−12dBFSへゲインを調整。
3. 先頭8msと終端最大120msにフェードを付加。ゲーム再生時にも短い終端フェードを適用。
4. 共通音量の初期値は55%。紙・風・機構・回転は、さらに用途別に控えめな再生レベルに設定。

ファイルのMP3にはエンコーダの余白があり、実ファイル長は採用区間よりわずかに長くなります。ゲーム内は指定区間までの短い再生です。

8ファイルの合計は81,423バイトです。LUFSの統一や、人が感じる音量の等しさを保証した処理ではありません。ピーク基準の調整だけで主観音量は一致しないため、最終調整は未完了です。

再現用：[prepare_sfx.cjs](../research/studio/prepare_sfx.cjs)。公式から正規取得した元ファイルを素材名のMP3として指定ディレクトリへ置いて実行します。

```sh
node research/studio/prepare_sfx.cjs OFFICIAL_DOWNLOAD_DIRECTORY assets/studio-sfx
```

取得元・区間・ゲイン・実測秒数・SHA256は[measurements.json](../assets/studio-sfx/measurements.json)に保存しています。

## 再生制御と保存

- 外部音源・オシレーター・ノイズ合成・BGM・ループ再生は使用しない。
- ユーザー操作でAudioContextを開始。読み込み・再入室・合格記録の復元だけでは再生しない。
- 連打は抑制。新しい操作へ移ったときは古い音を短く減衰させ、合格音が配置音で抑制されないようにする。
- 読み込みが遅れた音は約1.8秒を超えて後から鳴らさない。音源の失敗・音声APIの不在で試験を止めない。
- ON/OFFは既存キー `magic-academy-sfx-v1` を維持。音量は別キーに保存し、試験のセーブへ混ぜない。
- 一時停止・ページを隠す・ページを離れる場合には再生中・待機中の音を止める。
- iPhone対策として、ユーザー操作内での開始・再開と、Web Audioのゲインによる音量調整を使う。ただし実機検証は未実施。

## 正規取得の手順

掲載ページで素材名を探し、名前側のプレビュー操作と、右側のダウンロード用矢印を区別してください。取得は公式のダウンロード用リンクから行います。外部サイトへ音声ファイルのURLを埋め込む方法は使いません。

今回、取得できなかった4候補も上表の掲載ページから確認できます。初回候補の詳細は[一次調査](RESEARCH_SFX_CANDIDATES.md)を参照してください。
