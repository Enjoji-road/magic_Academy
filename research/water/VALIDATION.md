## 検証した範囲

| 対象 | 結果 |
|---|---|
| 既存作品の保持 | 基準 `67ed2573815ce0af96a66e3d55188467ed1fee57` の追跡済み66ファイルを全てバイト比較。一致。旧炎・土・回廊・共通音声は変更なし |
| 独立した物理計算 | Python、18,311チェック。625測定条件の終状態、圧力・気体の物質量、開口と気泡の整合を検査 |

| 唯一性と削除試験 | 公開銘板で限定した構造の候補を全探索。全観測で唯一解、各主要観測を一つ削除すると別解あり |
| 表示・採点・保存 | JSDOMによる5,183チェック。実際のHTML・JSを実行し、準備→給水→記録→台帳→合格を操作 |
| 観測順序・繰り返し | 同条件の記録を統合。観測だけで合格しない。全625条件を記録しても合格状態は変わらない |
| 保存復帰 | 観測、記入途中の台帳、メモ、合格が復帰。他科目の保存値は変更しない |
| 異常な保存 | 古いversion、別puzzle、壊れたJSON、範囲外の値は採用しない。保存された偽の水位は使わず、条件から再計算 |
| エラー耐性 | localStorageが使えない、音声APIがない、音声取得が失敗した場合も合格まで操作可能。保存不能を表示 |
| 音声制御 | 無操作で音源を読み込まない／鳴らさない。共通のON/OFFを維持。初回合格のみ鐘。BGMなし |
| UIの安全性 | メモは文字として扱い、スクリプトにならない。拡大図のSVG IDが主図と重複しない。異属性の外周操作で測定の気泡を発生させない |
| 新回廊 | 水の未受験・挑戦中・合格・再入室を反映。既存試験の記録を読むだけで書き換えない |

## 実行

リポジトリのルートから：

```sh
python3 research/water/verify.py
STUDIO_JSDOM=/path/to/node_modules/jsdom node research/water/test_water.cjs
node --check water-model.js
node --check water-app.js
node --check academy-water-progress.js
```

検証時は既存のテスト用JSDOM 26.1.0を使用。ゲーム自体はビルド・npm依存なしのHTML/CSS/JSで動く。Pythonも標準ライブラリのみ。

## 未確認・残る課題

- 実ブラウザの画面描画、320px〜の全レイアウト、iPhoneのタッチ・画面回転・音声出力は未確認。管理されたブラウザQA機能が利用できないため、代替ブラウザの導入や独自サーバーによるQAは行っていない。
- 装置SVGは静止画にして形状と目盛りの配置を点検した。この変換環境は日本語フォントが不足しており、日本語の描画確認には使えない。Web画面全体のスクリーンショット検証とは異なる。
- JSDOMの音声APIは模擬実装。音量・音質・iPhoneの実際の再生を検証した意味ではない。素材の聴取評価は行っていない。
- 流れの時間発展・熱交換・実際の弁や表面張力の実験は未検証。準静的な終状態を近似した試作。
- 初見難易度、空気への気づきの自然さ、発想後の六行の照合が作業に感じられないかは、人間のテストプレイが必要。
- 「装置図の復元」を課題に採用した。中央水槽を特定の水位まで満たす問題の完成を報告するものではない。
- 有効な完全図を無制限に提出すること自体は禁止していない。少数の状態操作で偶然合格する仕組みを避けたが、理論上の総当たり不能は主張しない。
- 土による再考察は外周の可動石と同じ排水系を使う拡張余地のみ。卒業試験は未制作。
