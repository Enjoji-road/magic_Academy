# 『魔法学校』デザインガイド v1.0

作成日：2026-10-20　／　対象：試験一覧・炎魔法学・水魔法学・風魔法学・土魔法学・卒業試験

## 1. コンセプト

**「格式高い魔法学院 × 少し豪華な実技試験室」**

古く権威のある学院の歴史を感じられる意匠を共通言語とし、各教室には属性の個性を際立たせる。装飾は試験の緊張感を作るが、推理に必要な文字・形・操作の視認性を損なわない。

- 共通モチーフ：濃紺の石造建築、真鍮、古金、羊皮紙、刻印、細い額縁、学院の星紋。
- 基本比率：**落ち着いた学術感 70%／属性らしい演出 20%／儀式的な豪華さ 10%**。
- 見た目が豪華でも、プレイの操作回数を増やさない。
- 試験ごとに専門性を強く演出する。異属性を使う可能性は隠さず、四属性の魔法ボタンは常に共通の場所に残す。
- 見た目の思い込みと、嘘のルールは別。文言で異属性を「使用禁止」と断定しない。

## 4. 画面の共通構造

1. **学院共通帯**：ARCANE ACADEMY、教室名、戻る、設定。
2. **試験の課題**：羊皮紙パネル。できることと成立条件を正確に記述。
3. **魔法選択**：炎・水・風・土を同じ並び・同じ押しやすさで表示。現在選択中の属性を明確化。
4. **主装置**：最も広い面積。図の拡大機能は任意。画像中の文字はスマートフォンでも判読可能。
5. **観測と記録**：再観測しやすく、未確認と確認済みが分かる。自分でメモ可能なら自動採点と切り離す。
6. **解答／提出**：余計な誘導質問を置かない。入力値が見やすい。
7. **合格演出**：学校印を儀式的に押す。合格記録は保持したまま再入室可能。

**スマホの優先順位**：問題文 → 装置 → 操作 → 記録 → 解答。固定フッターで装置を覆わない。

## 5. 炎魔法学『灯樹の原像』の具体方針

- ヘッダーは学院共通の真鍮枠＋炎色の細い装飾。演出は控えめで、観測壁の数字が第一主役。
- 燭台は「I」「II」と明記。選択時は灯具・光源の状態だけを一貫して変化させる。
- 灯葉はA〜Fを識別できる銘板付き金属札として描く。上面図の位置と観測壁の目盛りを統一。
- 観測記録は「I」「II」の2枚の羊皮紙カード。仮説メモは解法誘導をしない自由記述。
- **装置の仕組み**：見たい人だけ開く任意の説明。単独札→二枚重なり→共通する穴だけ光る、の短い図解。B=8など解答手順は書かない。
- 数字入力は登録台帳の儀式として表現する。入力が正解に近づいているかを演出で漏らさない。
- 合格時だけ灯火を順に点灯し、黄金色の院印を見せる。途中の正解推理に特殊演出を入れない。

## 6. 魔法と「思い込み」の扱い

- 各教室の見た目は所属属性を強く印象づける。ただし異属性のボタンを隠したり、無効な操作だと決めつける文章は使わない。
- 別属性で起きる現象も事前に定義した基本能力に沿う。正解のときだけ秘密の新能力が生える演出は禁止。
- 卒業試験では「以前からできた操作の見方が変わる」方向で驚きを作る。再訪時も最初の合格を取り消さない。

## 7. 音声・設定 v1.0

### 採用BGM

- 曲名：**想い出の魔法**／提供：**BGMer**。
- ユーザー提供の LONG 版（約10分30秒）を使用。配信の負荷を抑えた96 kbps MP3版を作成するが、全曲を保持する。
- クレジット：`音楽：BGMer（https://bgmer.net/）` を設定パネルへ常時表示。

### 設定UI

- **⚙ 設定**ボタンを試験一覧・各教室に共通設置。
- `BGMを再生／一時停止`、音量スライダー 0〜100%、ミュートを表示。
- 初期状態は**無音**。再生はユーザー自身のタップから始める（ブラウザの自動再生制限を守る）。
- 初期音量は**25%**。突然大きな音を鳴らさない。
- 音量・ミュート・再生位置は保存し、別の試験でも維持。フルページ移動で一度音が切れることと、iOSで再開にタップが必要な場合があることを明示。
- iOSを含め音量を調整するため、Web AudioのGainNodeを優先利用し、非対応時はHTML audio.volumeへフォールバック。
- ファイル読み込みに失敗した場合は「再試行」を提示し、謎の進行は止めない。
- `prefers-reduced-motion`設定では過度な火のゆらぎや装飾アニメーションを抑える。

### 音源の公開形式

- GitHub Pagesでは容量・ツール連携の都合上、全曲をバイナリ分割ファイルで格納し、再生前にブラウザで連結してひとつのMP3として扱う。
- 点灯・操作などの効果音は別設定で後日追加可能。BGM音量は効果音より控えめ。

- **今回**：本デザインガイド確定、全教室共通のBGM設定、音源配置、クレジットの実装。
- **次**：炎実験版の主装置・記録・説明イラスト・合格演出をこのガイドに沿って正式改修。仕掛けのルールは変えず、初見視認性をテスト。
