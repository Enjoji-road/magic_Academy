# 風魔法学・帯の研究試作

試作入口：../../wind-ribbon-experiment.html

初見で遊ぶ場合は、以下の研究ファイルを先に開かないでください。

- `RESEARCH_SPOILERS.md`：3構造の比較、全配置、正解、物理モデル、検証の限界。
- `material-layout-SPOILERS.svg`：展開図・接続図・文字配置。
- `verify.py`：アプリのロジックを呼ばない独立検証。
- `verification.json`：接続・読み・座標・遮蔽の結果。
- `test_model_and_ui.cjs` / `ui-verification.json`：独立座標との照合とDOM操作・保存の検証。
- `browser-verification.json`：実ブラウザで確認した範囲と、実機未確認の区別。

これは研究試作です。構造上の一意な読順と、二つのひらめきが初見で自然に起きることは、別の検証項目です。
