## 0. 結論と採用判断

五つの異なる魔法法則系統を比較し、**A「支え手の継承」**を、遊んで判断するための第一候補に選んだ。独立試作名は**『手を離した、その先に』**。

中心は「魔法が起こした働きを、別の魔法の支えにできる」という新規法則である。四つの術を使う順番を当てる問題ではない。術者からそれぞれ伸びていた四本の関係を、同じ一つの環へ結び直す。すると手を離しても、その状態が維持され、空の灯座に光が残る。

回廊の先輩の灯りにも、同じ四種類の働きが見える。術者へ戻る尾はない。自分で同じ状態を作ると、先輩が何を残したのかが画面上の出来事として分かる。

**ただし、この試作を完成作問としては採用しない。次の二点が残っている。**

1. 「四属性の一つの環」を思いついた後なら、環の向きと並びは六候補しかない。観測せず六回試す突破を、この版は防げない。625状態中唯一、という数字を総当たり耐性の根拠にはしない。
2. 三つの受け渡しが既知で、四属性の一環を作ると予想できれば、残る受け渡しは予測できる。四つの属性は現象に必要だが、四つの再訪を独立必須にはできていない。

さらに、四つの結果を表すカードと線が、魔術より接続問題に見える危険がある。魔法の法則を試せる操作系は作れたが、魔法学校の卒業試験として十分に面白いかは未判定である。初見テストを経ず、演出の完成へ進める段階ではない。

この限界を消すために、対象候補や極性、番号、試行制限を追加することはしなかった。第3次の成果は、科学装置を中心から外した魔術の候補比較と、状態から本当に動く試作、そしてその試作が許す抜け道を具体的に調べたことである。

## 3. 魔法法則の候補五案

ここでは各案を別の状態構造として扱う。Aは有向関係と保持、Bは対の保存・相殺、Cは対象の同一性、Dは余韻の時間、Eは作用域の重なりである。名前だけ変えた属性レシピではない。A以外は検証コード・実動試作を制作していない。

### A「支え手の継承」— 魔法が、別の魔法の支えになる【試作候補】

**法則。** 魔法の働きには余韻がある。術者がその余韻を支えている間に、受け取れる別属性の余韻へ触れさせると、その働きを手の代わりの支えにできる。

| 定義 | 内容 |
|---|---|
| 四属性 | 炎は形を灯に、水は灯を映りに、風は映りを巡りに、土は巡りを形にする。単独では術者が直接支えられる |
| 作用対象 | 物理物体への通常作用と、露出した余韻への受け渡しを区別。普通の光、液体、布、石そのものは余韻ではない |
| 発動条件 | 受け手の術を使い、供給側の余韻へ触れる。供給側が存在し、対応属性であり、手またはさらに別の術に支えられている |
| 状態変化 | 受け手に「どの余韻に触れたか」という関係が残る。手を離すと、この関係が働きを維持できるかが現れる |
| 持続 | 手に支えられた開いた鎖は手がなくなると薄れる。全四属性の閉じた関係は、初めに励起した灯座の魔力がある間、手なしで働きを保つ |
| 制限 | 同属性、自分自身、対応しない余韻、普通の物体では代替不可。燃料は有限。封緘された他人の術の裸の尾には直接触れられない |
| 観測 | 受け手だけ手を離す／供給側も離す、物体／余韻、対応する／しない相手を比較 |
| 再現 | 同じ存在・関係・手の支え・魔力量なら同じ結果。訪問順、過去の失敗、操作回数で変わらない |

**誤解と発見。** 四種類の術は、四人分の術者のように別々に支えなければならないと思う。実際には四つが互いを支えられる。卒業とは四術を使い続けることではなく、自分の手を離せる関係を残すことだった。

**光。** 炎の出力「灯」が、閉じた関係の一部として残る。空の灯座に置いた有限の魔力が光を生み、学院が補給する。通常の油火を永久の炎へ変えた、という設定ではない。

**既存との相性。** 物理状態を新規法則の計算に戻さないため、通常の光学・等温モデル・帯・石の解は保持できる。余韻の見た目と対象判定の追加は全科目で必要。詳しい弱点は後述。

### B「対の返礼」— 魔法は、結果と同じ大きさの“空き”を残す

**法則。** 一回の魔法は、現れた側と、受け取られなかった側を対で残す。異属性が同じ対に作用すると、物を消すのでなく、余った側同士を釣り合わせられる。四種類の対が同じ対象の上で釣り合うと、術者へ返るはずの余韻が一粒の灯種として定着する。

| 定義 | 内容 |
|---|---|
| 四属性 | 炎＝灯と影の術痕、水＝映りと映っていない面、風＝行きと返り、土＝置いた形と空けた形 |
| 作用対象 | 魔法の正負の術痕。実在の空気や暗闇を燃料と同一視しない |
| 発動条件 | 同じ対象に属する対の片側を選ぶ。異なる対を返礼させ、全属性の残量が零、灯種だけが残る条件を作る |
| 状態変化 | 対の残量が移る。間違った側を選ぶと一方の尾が伸び、相殺できず戻る |
| 持続 | 灯種は有限量の魔力を保存。補給で光を維持する。全残量零でなければ手を離すと術痕が戻る |
| 制限 | 対の所属対象は変えられない。普通の影を集めても術痕にはならない。二属性だけでは全四対は釣り合わない |
| 観測 | 片側だけでは尾が伸び、対の反対側に適切な属性を使うと尾が縮む。同じ量の返礼なら往復で元へ戻る |
| 再現 | 同じ対と残量なら同じ。時間や順序ではなく残った状態で決まる |

**四再考察。** 炎＋風で影側の尾が動く。水＋土で水面と映りのない側の対応を固定する。風＋水で同じ一縁の行き返りが別の対ではないと分かる。土＋炎でCを空けた位置にも対の片側が残る。

**大きな発見。** 四教室で「何もない」と思った側は、同じ魔法が返礼を待っていた場所だった。最初の回廊の空の灯座は、空っぽではなく、受け取れる側だったと捉え直す。そこへ釣り合った術痕を残す。

**長所。** 四つの通常試験の負の情報と響く。特に風・土の構造を強く使える。**問題。** どの余りがどれと釣り合うかを恣意的に決めると、符号付きの四スイッチになる。灯種が残る理由も、相殺で全て消える法則との差を観測で教える必要がある。現在は独立一意性も未確認で、Aより規則説明が多い。

### C「名を移す水」— 魔法は材料ではなく、対象の同一性を追う

**法則。** 魔法は、一度対象として受け取った「同じもの」という関係を追い続ける。水で作った写しを原物から独立させ、風で写しへ向かう指示を移し、土で新しい拠り所を確定すると、元の魔法を奪わず新しい担い手にできる。

| 定義 | 内容 |
|---|---|
| 四属性 | 炎＝一対象へ灯の働きを与える、水＝形を共有する写しを作る、風＝対象を指す尾を運ぶ、土＝新しい対象として定着させる |
| 作用対象 | 原物・写し・対象を指す関係の集合。材料の交換そのものではない |
| 発動条件 | 写しが原物と関係を持っている間に尾を移す。土で確定した時点の所属で結果が分岐 |
| 状態変化 | 同一視する集合の分割と、どこに働きが属するかが変化 |
| 持続 | 独立した新対象に灯と有限魔力が残る。関係未分離なら原物の変化を追い、手を離すと戻る |
| 制限 | 単なる似た物は写しにならない。無限複製は不可。分割時に術者が自分の魔力を拠出する |
| 観測 | 原物を動かすと追う像／独立して残る像、同じ布の離れた部分／別の布、土で確定する前後を比較 |
| 再現 | 同じ所属と確定状態なら同じ。過去の呼び名だけで判定しない |

**四再考察。** 炎＋水で投影像と金属札の同一性を区別。水＋風で水量を運ばず像の所属だけが移る。風＋土で課題面を別対象として切り離せないことを確認。土＋水で動かしたCと残った位置は別対象だと分かる。

**大きな発見。** 先輩の灯りを「火の材料」として持ち帰るのでなく、その学びを受け取る新しい対象を作る。自分の灯座に写しの所属を確定し、自分の魔力で新しい灯にする。

**長所。** 継承の意味と帯の一枚性が強く響く。**問題。** 水だけに複写と所属の能力が集中し、土の確定が作者都合になりやすい。原物を奪わないことと、増え続ける術の量を矛盾なく示すには、さらに相当量の比較が必要。元の試験の物体同定を覆さない慎重な領域分離が要る。

### D「余韻の時制」— 四属性は、同じ術の異なる時点を扱う

**法則。** 物理的結果は変えないが、魔法の余韻には直前・現在・次に渡せる状態がある。四属性はその別々の時点に作用する。過去の余韻を呼び直し、次の受け取り先を先に置くことで、手を離した未来にも灯る状態を作れる。

| 定義 | 内容 |
|---|---|
| 四属性 | 炎＝現在の出力を起こす、水＝直前の余韻を保つ、風＝次の受け取りへ渡す、土＝時点が変わっても同じ形を保持 |
| 作用対象 | 最後の一状態だけを含む余韻。世界の過去・解答履歴を改変しない |
| 発動条件 | 直前の状態が保持され、受け取り先と保持先が同じ一対象に属する |
| 状態変化 | 有限の状態列のどの時点を参照するかが変わる |
| 持続 | 一夜分の反復を灯座に固定。魔力の有限消費と定期補給は別途必要 |
| 制限 | 二回以上前の余韻へ戻れない。普通の水位、石の置き方、札の過去は戻さない。未知の未来を知る力でもない |
| 観測 | 同じ装置で余韻だけが一つ前の状態を示す。物理目盛りとの相違、切替後一回で消える記憶を比較 |
| 再現 | 同じ一段の記憶なら同じ。状態列を明示的に保存して再現できる |

**四再考察。** 炎＋水で燭台を消しても一つ前の術の像だけを保持。水＋風で注いだ後の像を次の場所へ渡す。風＋土で一周前の尾が同じ境界へ戻ることを固定。土＋炎でCの移動前後の輪郭を現在の灯として起こす。

**大きな発見。** 四属性は同時に四つ置く能力ではなく、一つの術が次へ進むための時制だった。自分が去った後を受け取り先にする。

**長所。** 「次の生徒へ」を操作の意味にできる。**問題。** 初回の物理状態を巻き戻せると誤認されやすい。順序の手順問題、状態履歴の管理作業に落ちやすく、四術の普段の能力との距離も大きい。再考察を先に見つけた場合の説明負担が五案で最も重い。

### E「ひとつの術域」— 四つを同じ対象へ使うと、作用する境界が変わる

**法則。** 単独属性の術域は見た物体に付く。異属性の術域が同じ連続した境界を共有すると、一方の内側と他方の外側を一つの対象として扱える。四属性の術域が完全に一致すると、灯は物体表面ではなく、囲まれた場所全体に現れる。

| 定義 | 内容 |
|---|---|
| 四属性 | 炎＝域を照らす、水＝接している域をつなぐ、風＝境界の向きを選ぶ、土＝域の境界を確定する |
| 作用対象 | 魔術的な作用域と連続した境界。建物の見取り図そのものではない |
| 発動条件 | 四域の範囲と向きが同じ対象を指す。単に近くに四術があるだけでは不可 |
| 状態変化 | 内・外・境界として何を含めるかが変わる。ずれた域は別々の反応になる |
| 持続 | 四域の一致を土の術が保持。照らす魔力は有限補給 |
| 制限 | 離れた別物を見た目だけで同一域にはできない。建築の裏側を後付けでつながった扱いにしない |
| 観測 | 一部に触れて全体が反応する／接触しても独立のまま、風の帯で内外が一周では元へ戻らないことを比較 |
| 再現 | 同じ境界集合と向きなら同じ。描き順や受験順は無関係 |

**四再考察。** 炎＋水で札と投影像の域を区別。水＋土で水を囲む外側の支持面を域として捉える。風＋土で一境界を二つの辺と誤認していたと分かる。土＋風で九石の域とその空きの域が異なると分かる。

**大きな発見。** 回廊を、四つの扉の集合ではなく、人を迎える一つの術域として使う。空の灯座の内部が新しい対象になる。

**長所。** 四つを一つとして捉える発見と帯に強い。**問題。** 境界の対応を絵で転記する作業に戻りやすい。回廊に大きな同一域の証拠を追加する改修が必要。建築・位相の問題が再び主役になる危険があり、今回の方向転換にはAより弱い。

## 5. A案の魔法法則を固定する

### 5.1 普通の結果と、術の余韻

炎で点けた燃料灯は、手を離しても物理的に燃え続けてよい。水を止めても注いだ水は残る。移した石は、元へ巻き戻らない。既存の四科目で成立していたことを変えない。

今回、比較するのはそれらの周囲に細く見える**術の余韻**である。これは新規提案の魔術的対象。普通の炎や水が消えることと、余韻が手の支えを失うことは違う。試作でも、炎の通常投影と、新しい「灯」の余韻の計算を分けている。

「水は光なら何でもコピーして永久に保つ」という規則ではない。水の術は、接触できる裸の「灯」の余韻を受け取る。見えているだけの普通の光、封緘の外へ出た光では、支えの関係は作れない。先輩の完成術は透明封緘で保護されており、外からその術そのものを書き替える操作はない。この封緘も正式版では最初から描く必要がある。

### 5.2 四属性の変換

| 受け手 | 手の代わりに受け取れる余韻 | 起こる新しい働き | 成立しない例 |
|---|---|---|---|
| 炎 | 土の「形」 | 固められた術の輪郭を「灯」として現す | 普通の石を温めるだけ、炎自身の尾、映りの尾 |
| 水 | 炎の「灯」 | 灯の働きを「映」として持つ | 灯具へ直接注水、普通の壁の明るさ、巡る尾 |
| 風 | 水の「映」 | 映りを水量から切り離し、「巡」として運ぶ | 水滴を吹き飛ばすだけ、布へ吹くだけ、灯の尾 |
| 土 | 風の「巡」 | 巡っている一続きの働きを「形」として留める | 窓台を動かすだけ、別々の見かけの辺、映りの尾 |

手で支えている間は、対応しない相手へ触れても術者自身が働きを起こせる。したがって接触した瞬間に正誤の色は付けない。手を離す比較で、何が支えになったかを知る。

これは四つの鍵穴ではない、と作者が言うだけでは足りない。少なくとも、普通の物体と余韻を別の対象として試せ、支えを外すと連鎖して変化し、同じ現象を別の場所で再現できる必要がある。その三点を試作で操作可能にした。ただしカード接続に見える危険は残る。

### 5.3 状態モデル

各術 `i` は次を持つ。

- `exists[i]`：その術の余韻を起こした状態がある。
- `manual[i]`：術者が直接支えている。
- `from[i]`：触れている余韻の出所。四属性または無し。
- 灯座全体の `charge`：0〜8夜分の有限魔力。

`take(炎)=土, take(水)=炎, take(風)=水, take(土)=風` とする。

残る働き `live` は、次の式の**最大固定点**で決める。

`live[i] = exists[i] AND (manual[i] OR (from[i] = take(i) AND live[from[i]]))`

本試作の一意性は、新灯座の上に各属性の余韻を一つずつ置く作用域に限る。複数灯座・複数の同属性余韻を自由に増やす一般体系や、そのUIは未設計である。通常の炎で二つの燃料灯を点けられる能力を、一属性一対象に制限する提案ではない。

最大固定点を選ぶ理由は、起こしてある四つの術が閉じた状態を保持できる、という今回の新規法則を明示するため。固定点だから現実に永久機関が成立する、と主張するものではない。起こしていない術が勝手に生まれるわけでもない。灯の発光にはさらに `charge > 0` が必要である。

JavaScriptは全存在ノードからの消去反復、Pythonは各支え鎖をたどり、手・不適合・循環を検出する別算法を使った。

### 5.4 合格と、光が生じる因果

初回成立は回廊の新灯座について、四つの余韻が存在し、四つとも手の支えがなく、四つが残り、灯座に魔力があること。

入力順、訪問、ノート、見た記録、魔法の使用回数は条件に含めない。「正しい順に押したから光る」イベントではない。誤った状態では働きが薄れ、正しく閉じた状態では灯の余韻が残る。合格表示はこの光の成立に反応する。

線はプレイヤーが触れた関係を描くだけで、正しい接続図を自動作成しない。残る／薄れるという結果以外に、正解へ近づいたことを示す採点や音はない。

### 5.5 光の持続と学院の保守

閉じた関係が保存するのは**術の働き方**であり、無限のエネルギーではない。試作では炎の魔法を使うと灯座へ8夜分を蓄える。発光一夜につき1を消費する。8夜後、形は残るが光は眠る。学院は7夜ごとに炎の魔力を補給し、卒業生の結び方をほどかず維持する。

この数値は現行設定ではなく、新規の運用規則。理想化した魔術の仕様であって、実物燃料の寿命の測定値ではない。試作の「研究用：一夜後」で有限性を確認できる。待ち時間や試行回数制限には使わない。初見の課題文と先輩の灯座の保守記録に補給を出し、終了後に都合よく追加しない。

炎だけで補給できるのは、四属性の環が既に作られている場合。炎だけで新しい環を作ることはできない。日々の保守と、卒業生が作る術の構造を分ける。

### 5.6 増え続ける光の扱い

現在の三灯は展示単位の簡略図。正式設定では個人の術を小さな灯座札に保存し、期ごとに同じ灯架へ収める。入口の灯架は現在の迎え灯を担い、過年度の灯座札は学習用の旧灯廊・記録庫へ移す。卒業のために先輩の灯を消したり上書きしたりしない。

全卒業生の灯を永遠に同じ回廊で同じ明るさに足し続ける、とはしない。展示と保守の範囲は有限にし、保存した術は再補給して同じ働きを再現できる。古い記録も将来の生徒が見学できる。この運用には正式版の美術・年次・収容数を定める作業が残る。無限の空間を魔法でごまかさない。

## 6. 四科目の再考察

### 6.1 炎室へ水 — 灯具でなく、灯の働きを映す

**現在ある装置。** 固定された六枚の金属札、二つの灯具、投影壁。

**追加する観測。** 点火中の術に細い尾を描く。水を灯具へ使えば今までどおり消える。水を灯の余韻へ使えば、壁の物理投影とは別に、小さな水の映りが同じ像を持つ。

**試作の操作。** 炎を選び装置へ使う→水を選び、現れた「灯」の余韻をタップ→水だけ手の支えを離す。映りは残る。炎の支えも離すと、余韻の映りは薄れる。燃料灯の通常投影を消すことは採点に使わない。

**ひらめき。** 水へ「別の情報」が出たのではない。同じ灯の働きが、水の術の支えになった。コピーした文字を回収する課題ではなく、像が何に支えられるかを見る。

**比較。** 灯具へ水＝消火。灯の余韻へ水＝映り。水の支えだけ外す／両方外す。札や穴は動かない。

**残る懸念。** 現行プレイヤーが、水を使えば像が物理的に屈折する話と誤認しないよう、術の尾と物理的な投影線を描き分ける必要がある。試作は尾を別の操作領域に置く簡略表現。

### 6.2 水室へ風 — 運ばれたのは、水量ではなかった

**現在ある装置。** 封印瓶、計量鐘、外水盤と外側の布。

**追加する観測。** 水を使った外水盤の余韻が水面の形を映す。風を布や水盤自体へ使う通常作用と、映りの余韻へ使う新しい作用を区別する。後者では映りが巡り始めるが、水は水盤に残り、瓶や鐘の値も変わらない。

**試作の操作。** 水を外水盤へ→風を「映」へ→風だけ手を離す。巡りは残る。水の支えをなくすと巡りも薄れる。封印瓶の通気操作や実験後の外観も切り替えられるが、再考察は外水盤で行う。

**ひらめき。** 風が水そのものを運ぶ必要はない。水の術が持っていた映りを、別の働きへ渡せた。

**比較。** 物体へ風＝外の布が揺れるだけ。映りへ風＝巡り。水面の物理状態と、術の巡りの有無は別。

**保護。** 加熱、内部への送気、瓶や鐘の移設、圧力・水頭の変更は一切提案しない。試作の満水表示は通常実験の簡略外観であり、SIモデルを別の値で計算し直したものではない。

### 6.3 風室へ土 — 見た一辺でなく、一続きの働きを留める

**現在ある装置。** 半ひねりの一枚の織布、平らな課題面、窓台と留め具。

**追加する観測。** 風の余韻の尾が銀縁に沿う。土を窓台へ使う通常作用と、巡っている尾へ使う作用を区別する。後者は、タップした見かけの上辺だけでなく、ひねりを越え、課題面まで含む同じ一境界を「形」として受け取る。

**試作の操作。** 風を装置へ→土を「巡」へ→土だけ手を離す。「中央一周ぶん追う」で始点の反対の縁へ、二度で同じ始点へ戻る。正面／横からの観測を切り替えられる。

**ひらめき。** 土は石を動かすだけ、風は布を動かすだけと思っていた。土は、風が巡らせている同じ一つの働きの形を留められる。しかも作用単位は画面上の辺でなく、物理的につながる境界だった。

**帯の必然性。** 通常の輪なら境界は二つあり、一方から始めた巡りは反対側へ渡らない。現在の帯なら2000境界節点が一成分、1000節点後に反対の辺へ、2000節点後に同じ場所へ戻る。平らな課題面の両縁432節点も含む。新しい資料を裏へ貼り足す必要はない。

**保護。** 布を切らず、留め具も動かさず、文字の読字条件を変更しない。試作は現行 `point / project / next` の座標・同定を読み取り利用。余韻を示すため裏へ続く縁も図示するが、これは通常試験の遮蔽を変更した正式レンダラーではない。

**限界。** 数学的に帯であることが土の唯一の受け取り先を決めるわけではない。一本の作用単位を観測するために帯の構造を活用している。最終の一灯は単純な環でも成立するため、メビウス構造自体が卒業で独立必須にはなっていない。

### 6.4 土室へ炎 — 燃やす物ではなく、術が与えた形を灯す

**現在ある装置。** 完成済みの九石と、動かせるC石。

**追加する観測。** Cを持ち上げると、石そのものとは別に、動かす術の輪郭が見える。普通の石へ炎を使うだけでは温まる。土の余韻へ使うと、物が燃えていない場所に、その術の形をした灯が現れる。

**試作の操作。** 土でCを持ち上げる→炎を「形」へ→炎だけ手の支えを離す。形の灯は残る。土の支えもなくすと薄れる。Cを元の同じ場所へ戻して比較できる。

**ひらめき。** 「炎の対象＝燃える物」と思っていたが、対象が別の術であれば、その術が与えた形を灯にできる。これは新規の相互作用であり、普通の石が突然燃える設定ではない。

**保護。** 完成配置を別の解へ動かさない。九石の形・◆◇・三連石条件はそのまま。第二の石盤問題はない。

### 6.5 四再考察を統合する

四つの発見は「四つの暗号片」ではなく、同じ受け渡しの異なる一辺。

`土の形 → 炎の灯 → 水の映 → 風の巡 → 土の形`

教室で見たのは、どれも手に始まって他の術へ続く短い鎖だった。四辺を同じ新灯座へ作れば、自分の手へ戻さず、相互に支える一つの術にできる。

ここで法則が分かった後に長い文字転記はない。四つの関係を一度作り、手を離すだけ。図や観測を自動的に正解順へ並べる機能もない。

## 7. 回廊の秘密、課題、最後の操作

### 7.1 最初から必要な伏線

正式統合では、初回の回廊から次を描く。現行に既にあるとは扱わない。

- 期印の入った先輩の灯座。薄い透明封緘の内側に四種類の細い働きが見える。
- 術者へ伸びる尾がないこと。教室での手の支えとは外観が異なる。
- 一つの空の灯座。壊れたり消えたりした灯具ではなく、これから置く場所。
- 七夜ごとの補給札。永遠の魔力を後から追加しない。

四科目合格後に示す課題文案は、試作と同じ「この回廊に、あなたが手を離しても灯る光を一つ残しなさい」。先輩の灯りと、各教室で見た術の尾が同じ形を持つことから、装置を振り返る動機を作る。

最初から「四属性を環につなげよ」とは書かない。回廊の観察だけで発想した人は、その仮説を教室で確認できる。早期発見を失敗扱いしない。

### 7.2 最後の操作の一例

1. 空の灯座へ炎を使う。今は自分の手で灯を支え、8夜分の魔力を預ける。
2. 水を選び、「灯」の余韻へ触れる。
3. 風を選び、「映」の余韻へ触れる。
4. 土を選び、「巡」の余韻へ触れる。
5. 炎を選び直し、「形」の余韻へ触れる。最初の灯を、土が与えた形で支え直す。
6. すべての手を離す。

主要な操作は六回。属性の選択を含めれば十一回のタップが一例となる。入力欄へ四答を並べたり、四つの呪文を順番入力したりしない。

**重要なのは5。** 一度ずつ使った時点では、最初の灯が自分の手に依存した鎖にすぎない。最後の働きを最初の術の支えにすることで、四つを別々に扱っていた理解が変わる。ただし「最後に初めへ戻す」の一手が、簡単な接続問題に見える人もいるだろう。ここが初見テストの中心。

先に四属性の余韻を手で起こし、関係を逆順に作ってもよい。順番が唯一の正解ではない。現在の関係が同じなら同じ結果になる。まだ現れていない余韻は選べないため、「対象がない時の操作」と「対象がある時の操作」が同じ結果になる、とまでは主張しない。

### 7.3 点灯と卒業

手を離した時、計算上残った灯の余韻が灯座で発光する。これが成功条件そのもの。成功だから後付けで別の光を出すのではない。

画面は先輩の三灯に新しい一灯を並べる。「次の生徒の目で入口を見る」で入学側へ視点を移し、今作った光に迎えられる短い場面を出す。説明文を消しても、以前の灯と自分の灯が同じ形式で残ったことは見える。

手を離した瞬間の壮大な自動配線、光による正解図の提示、四魔法を順に自動再生する合格処理は入れていない。成功後の音は短い鐘のみ。先輩の灯りは消えない。

## 8. 論理検証と反例

### 8.1 実装した状態と、独立した計算

`verify_magic.py` はJSの正答判定を呼んで期待値を作らない。Python側に四対応を別定義し、支え鎖の追跡で結果を求める。JS側の消去反復とは異なる算法で14,641状態を比べ、全結果のSHA-256が一致した。

一属性の状態は「未起動」1通り、または「起動済み × 手2通り × 出所5通り」の10通り。計11通り、四属性で `11^4=14641`。存在しない相手を指す不正な参照も含む。固定された魔力8で比較した。全ての任意のJSONや、将来追加する状態を検証した数字ではない。

### 8.2 一意性と四属性の役割

| 検証 | 結果 | 範囲 |
|---|---|---|
| 四余韻があり、手なし、出所は無しまたは四属性 | 625状態中1状態が成立 | 同じ余韻各一つという試作の作用域 |
| 全状態のJS／Python比較 | 14641状態で一致 | 最大固定点と鎖追跡の一致 |
| いずれかの属性を除く | 各属性で成功0 | 自己保持の環が閉じない |
| 四関係を作る順番 | 24通りすべて成立 | 四つの対象を先に起こした場合 |
| 誤操作から正しい状態へ戻す | 14641状態から回復 | 起こし直し・結び直しは回数制限なし |
| 灯座の魔力 | 8夜後は発光しない。補給で同じ形を使用 | 永久発光とはしていない |

四属性はそれぞれ異なる型の受け渡しを担う。炎をもう一度使って水の映りを代替すること、普通の水を吹き飛ばして術の巡りを代替することは、定義したモデルにはない。これは現実の自然法則からの証明ではなく、観測可能に定義した作中の法則である。

### 8.3 法則を観測だけから唯一に決められるか

有限の観測だけで、あらゆる架空法則を排除することはできない。例えば「五回目だけ違う」「三属性同時だけ別の規則」も、未観測なら常に作れてしまう。

検証した仮説範囲は、場所と履歴に依存しない決定的な二属性の受け取り関係。四受け手×四供給の16ビット、65,536種類を考えた。

- 正の対応を四つ観測しただけでは、**4096種類**残る。追加の受け取りも認める法則が排除できない。
- 16組の正負を観測すれば、この仮説範囲では**1種類**に定まる。
- 一受け手の行を丸ごと欠けば、**16種類**の関係が残る。

試作ではどの教室でも余韻を起こし、相手を変えてこの比較ができる。全16回の転記作業を課す設計ではない。既知の四つの正の対応を応用すれば、実際に成立する環を作れる。法則の排他性を全て証明してから卒業しなければならない、という課題にはしていない。

従って「四室の短い観測だけで、あらゆる代替法則を排除して唯一の世界法則を証明できる」とは報告しない。

### 8.4 再考察を一つ省略した場合

大きな制約が見つかった。三つの対応が既知で「四属性を一つの環にする」という発想があれば、残りの一辺は環を閉じる向きから予測できる。スクリプトでも全四種類の省略に対して最終環の候補は一つ。

法則全体については省略した受け手の他の可能性が不定だが、最終操作については推測できる。この意味で、**四室の独立必須性は成立しない**。

これは、予測して試すという魔法研究の楽しさにもなる。だが依頼の「四つの発見を全て必要にする」を強く解釈するなら、本版はその条件を満たさない。訪問済みフラグや確認ボタンで四室を必須化することはしない。

### 8.5 総当たり

| 戦略 | 結果 | 評価 |
|---|---|---|
| 四属性を普通の灯座へ一回ずつ使う | 順序24通りすべて不成立 | 物体への使用履歴だけでは解けない |
| 四属性×四余韻を、行単位／列単位で順番に全部試す | 1152通りの単純走査で成功0 | 最後に同じ出所へ集まり、環にならない |
| 四つの出所を無作為に選ぶ | 625候補のうち1 | 候補が多いというだけで耐性を証明しない |
| 同属性も「無し」も除いて出所を選ぶ | 81候補中1 | 想定が進めば探索空間は小さくなる |
| 一つの四属性環だけを試す | **6候補中1** | 発想後の順列試行で突破可能。重大な未解決 |
| 個別に支えを外し、各受け手の相手を探索する | 最大で各3〜4比較程度 | 合法な法則実験として解ける。教室訪問を省略可能 |

最後の二つを隠して「総当たりできない」とはしない。特に、試作は仕組みを観測して学べるようにするほど、同じ操作が局所探索の道にもなる。

主な発想を得る前の無意味な全属性走査では解けないが、**中心の発想後の少数試行には弱い**。今の採用判断は保留。恣意的な試行上限・待機時間・選択肢増量で塞がず、初見テストでこの弱さが体験を実際に壊すか判断する。

### 8.6 別解の扱い

同じ最終関係を違う順番で作るのは正しい別手順で、禁止しない。回廊で自力の比較実験を行い、教室へ戻らず法則を理解するのも正しい代替経路。早期発見も合格を妨げない。

一方、普通の油灯を点けて置くだけで十分ではないのか、という物語上の別解には課題の文脈が必要。正式課題では「学んだ四つの術を、灯座に残す」ことと、燃料皿のない新灯座を最初から示す。油火の点火と、術の継承を区別する。試作はこの文脈を短くしているため、ここも初見で確認すべき問題である。

### 8.7 描画とモデルの一致、未検証の物理

風の布は現行の座標関数を直接呼ぶ。同定は `(1,v)=(0,-v)`。境界の2000節点と、課題面を含む経路を独立に確認した。風の余韻の観測位置も同じ座標から取る。

その他の教室は観測用の簡略SVGであり、光線の再積分、流体計算、重力、魔力の実物シミュレーションを作ったものではない。移された輪郭の内容も一般的な図形データとして全教室間で運んでいない。余韻の出所・支え・残存は実装状態だが、形状の変換表現は場面ごとの簡略描画である。

今回の新規法則を、現実の光学や永久機関の検証済み事実にはしない。正式統合時には、通常装置の描画と、余韻の対象範囲の整合を改めて検証する必要がある。

## 10. 初見プレイヤーの思考シミュレーション

以下は観測から起こり得る仮説の変化であり、「この位置で全員が気づく」とはしない。

### 順序1：四修了後、炎→水→風→土

**回廊。** 空の灯座に炎を使う。確かに明るくなる。手を離すと灯座の光は薄れる。最初は「長く燃える材料が要るのか」と考える。一方、先輩の灯座には炎だけでなく四色の細い働きが見え、手へ戻る尾がない。課題が四科目後に出たことと合わせ、各装置に同じ尾があったのを見直す理由ができる。

**炎室。** 水を灯具へ使って消火してしまう人もいる。装置を戻せるため失敗に罰はない。別の対象として灯の余韻を試し、水の映りを得る。受け手だけ手を離す比較から「水の術は自分の手でなくても支えられる」と仮説を作れる。ここではまだ「炎を使う間だけのコピー」でも説明できる。

**水室。** 風を水盤へ吹いても水量は移らない。映りへ触れると、その働きが巡る。先の「コピーを別の器へ入れる」という物理の解釈では、残る水と動く像を説明しにくくなる。「運ばれるのは水ではなく術」という仮説へ変わる。

**風室。** 土を窓台へ使うだけでは終わらない。巡りの余韻へ触れ、土の手を離しても形が残る。一辺だけと思った形がひねりと課題面まで続くため、魔法の対象は画面上の個別部品ではないと分かる。再考察が別資料の発見になっていないかを特に見る。

**土室。** 以前動かせないと思ったCを、今度は自由に持ち上げる。石に炎では温まるだけ。輪郭の余韻へ炎を使うと、燃える材料のない場所に灯る。ここで「土→炎」が加わり、先に得た炎→水→風→土が自分の手で終わらず閉じると見通せる。

**回廊へ戻る。** 四つを一回ずつ使っても、最初の炎の支えはまだ手。土の形へ炎を使い直す理由が分かる。手を離す前に、手へ伸びていた関係が同じ働きへ戻っていることを目で確認できる。六つの主要操作後に光が残り、先輩の灯と同じ外観になる。

**この順序の危険。** 四つの対応だけノートへ集め、最後を接続図完成として扱う人。成功しても「魔法の発見」と感じなければ改稿が必要。

### 順序2：通常の風で早期に土を試す→土→炎→最後に水

**早期の風。** 初回から四属性が選べるため、土で余韻を留めることに先に気づいてよい。読字の正解は変わらず、帯の一境界を理解する観測が増えるだけ。卒業用の記録を取っていなくても、現象は再現できる。

**土室。** 持ち上げたCの輪郭を炎で灯すことに気づく。土の形が炎を支えるなら、風→土→炎という短い鎖が作れると考える。この時点では水の役割が不明。四属性の全部入りが必要、と決めつける必要もない。

**炎室。** 水を灯の余韻へ使い、映りが残る。風→土→炎→水となったところで「風は水を受け取れるのでは」と予測できる。

**水室へ。** 予測した風を、物体ではなく映りへ試す。水量を動かさず巡りが続くことから仮説が確かめられる。これは確認の訪問であり、独立な情報回収ではない。この順序こそ四室必須性の限界を示す。

**回廊。** 関係を土から作り始めても、最後に全て同じ環へなればよい。初めに使った属性へ戻ることと、固定の呪文順序を暗記することは違う。別順序でも同じ状態が残ることで法則への納得を作る。

### 順序3：回廊で比較だけを続ける

四種類の余韻を出し、それぞれの支えを一つずつ離しながら相手を探索できる。これは試作の許す正しい観測経路である。四教室を飛ばしたとして合格を拒否しない。

その結果、作品全体を振り返る体験が弱くなる。この行動が多数を占めるなら、完成版へは進めない。対策は「回廊では実験禁止」ではなく、各装置でなければ見えない対象の性質を法則の内容にする改稿である。ただし現時点で、追加の恣意的規則なしに四室を独立必須にする解決は得ていない。

### 11.4 開発順序と中止条件

1. **この独立試作で初見テスト。** 実際の試行・観測・感想を取る。解法を説明してから遊ばせない。
2. 対応表を覚えるだけなら、機能を増やさずAを不採用にする。B/Cの対象の認識転換を再検討する。
3. Aを続ける場合は、カードの型だけでなく、元装置の一続きの余韻が直接触れられる試作へ置き換える。四室を独立必須にするための余分なパラメータは足さない。
4. 各教室一つずつ、通常版の描画の上へ観測レイヤーを試作。初回の合格と新規の法則が混線しないか検証。
5. その後で初めて、正式な四修了の導線と回廊へ統合。通しプレイと保存の回帰を確認。
6. 最後に、卒業の演出・学院史・灯架の年次運用を仕上げる。

新規の魔術体系を追加する以上、HTMLだけを一枚足せば正式四科目に自然統合できる規模ではない。モデルの隔離は容易だが、各教室の対象判定・描画・導線は中程度以上の改修になる。

## 14. 最大の未解決点
