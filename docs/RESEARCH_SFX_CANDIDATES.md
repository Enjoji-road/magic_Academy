## この資料の評価範囲

**以下は公式ページの掲載情報による候補比較であり、音声の試聴評価ではない。** この調査担当は音源を聴取・取得していない。秒数、ピーク音量、音圧、残響の実測はすべて未実施。説明からの予測は仮説として記載した。

実装担当が正規のダウンロード操作で取得できた音について、別途、実測値・試聴できた範囲・加工・採否を記録する。取得できなかった音を採用済み、再生操作だけを行った音を聴取済みとは扱わない。

## 一次選定の優先順位

最初に比較したいのは、点火・小さな金属機構・紙・石の摩擦・石の設置・水・風・合格音の8系統である。魔法発動専用音は、点火などの実物音だけで手応えが十分なら省略する。同じクリックで複数の大きな音を重ねる必要はない。

素材名に「魔法」とあることを採用理由にしない。魔法検索には戦闘用に見える素材もあり、火球、地割れ、雷撃などを静かな実験操作へ機械的に割り当てない。

## 取得後に残す比較記録

| 必須項目 | 記録する内容 |
| --- | --- |
| 取得 | 公式ページ上の素材名、正規ダウンロードの成否、取得日、ローカル名 |
| 数値 | 実測秒数、ピーク、平均レベル、無音の前後、想定の再生音量 |
| 聴取 | 実際に聴けたか、再生確認だけか、未再生かを区別 |
| 印象 | 静かな学院に合うか、反復で疲れないか、材質と属性が伝わるか |
| 操作との一致 | 1操作に対して長すぎないか、状態が変わらない再クリックで鳴らさないか |
| 加工 | カット・フェード・音量変更の有無と範囲。無加工ならその旨 |
| 採否 | 採用・保留・不採用と具体的な理由 |

目安として、頻繁な操作は1秒未満、合格音も数秒程度に収まる候補から確認する。これは実測値ではなく設計上の目標。繰り返し再生・BGM化・操作と無関係な試聴用サンプラーは設けない。
