## UI方針と変更点

学院共通の濃紺、真鍮、羊皮紙、細い額縁を使い、情報の主役を観測図・石盤に保ちます。教室の装飾から属性の専門性が伝わるようにし、魔法の選択は四属性すべて残しました。

炎は深紅・琥珀・真鍮の灯火観測室。燭台の金属部、点火に応じた光、金属札の配置図を整えています。投影の幾何・壁の像を作るパス・刻字規格には変更を加えていません。

観測I・IIは羊皮紙の記録として一か所に集約。自由記述のノートは独立保存とし、自動採点・解法の自動整理には使いません。装置・観測・台帳へ移動する小さなナビを用意しました。

任意の「装置の仕組みを見る」では、説明用の7セグメント札を使い、両方の穴を通る光だけが届くことを示します。試験の札の刻字や対応表は表示しません。すべての仕様・寸法・規格見本は引き続き確認できます。

台帳はインクで登録番号を記す様式。合格判定の後だけ、四つの儀式灯と学院の印を表示します。途中の入力に応じて灯火や印を変える処理はありません。再入室では合格音を鳴らしません。

土は苔色・砂岩・銅の封印石盤室。既存の石盤・プレビュー・回転・配置をそのまま使用し、棚と文字の読みやすさを調整しました。

水・風は、回廊に材質と色の方向性を示す準備中の扉だけを置いています。謎・正解・新しい魔法能力は作っていません。卒業試験も未制作の表示を維持しています。

## 保存と互換性

- 炎は既存の第4次研究の保存キー・版を継承。通常版の炎とは別記録のままです。
- 土は既存キー `magic-academy-earth-v2` を継承。
- メモは `magic-academy-fire-notes-v1` に保存し、試験の状態と分離。試験リセットでは個人メモを消さず、専用ボタンで消します。
- 効果音ON/OFFは既存キーを継承し、音量だけ新たに保存。
- 回廊は保存を読み取るだけです。合格済みでも再入室できます。

## BGMについての依頼の整理

同時依頼の一方には古いBGM維持の記述がありますが、音響依頼はBGM不使用を明示し、現行ガイドv1.1もBGM廃止を明記していました。現行リポジトリには `academy-audio.js` / `academy-audio.css` がなく、効果音のみの状態です。

そこでBGMを復活させず、設定の音量・ON/OFF・一時停止を効果音用として用意しました。曲名の表示はありません。素材の提供元は設定内に置いています。

## 検証方法と限界

既存のモデル・判定・保存アプリはファイルのバイト比較で基準コミットと照合します。新HTMLに対して、実際のイベントハンドラを通した正解までの操作、記録、メモ、消音、失敗時の継続をDOM環境で確認します。

古いモデルテストには、以前のコミットと既存ページをバイト比較する保持チェックがあります。今回以前の効果音導入ですでに変わったページもあるため、そのままの実行は保持チェックで失敗します。今回の統合検証では、保持比較だけを作業開始時の基準コミットへ更新して評価し、元のテストファイルは変更していません。数学・判定の検査は元の内容を実行します。

```sh
# jsdom 26.1.0を別途導入したテスト環境
STUDIO_JSDOM=/absolute/path/to/jsdom node research/studio/test_preview.cjs
node research/test_engine.cjs
node research/fire/test_interaction.cjs
```

これらは実ブラウザの描画、画面幅による実際のレイアウト、iPhoneのタッチ、音声デコード・出力を確認するテストではありません。今回の環境では対応ブラウザ制御が利用できず、実機相当の画面検証は実施していません。320px〜のCSS・拡大・図内スクロール・44pxの操作領域・動きを減らす設定を用意しましたが、実機確認は残っています。
