# 学院運営記録

2026-10-23に追加した、全プレイヤー共通の匿名統計です。通常の設定画面で「学院の設定」という見出しを5回続けてタップ、クリック、またはキーボードで操作すると開きます。

## 公開構成

- Web：GitHub Pages上の `academy-statistics.js` / `.css`。
- API：Supabase Edge Function `academy-statistics`。
- データベース：接続済みプロジェクト `jyxdjhrcowdijwzgqtyl` 内の `academy_stats_*` だけを使用。
- API URL：`https://jyxdjhrcowdijwzgqtyl.supabase.co/functions/v1/academy-statistics`。

既存のSupabaseテーブルや関数には変更を加えていません。必要なDDLの再現用SQLは `supabase/academy-statistics.sql`、デプロイ済みの関数ソースは `supabase/functions/academy-statistics/index.ts` にあります。

## 数え方

ブラウザは初回にランダムなUUIDを作り、`magic-academy-statistics-browser-v1` として端末内だけに保存します。Edge FunctionはUUIDをサーバーの秘密鍵でHMAC化し、元のUUIDをデータベースへ保存しません。

| 記録 | 発生条件 | 重複防止 |
| --- | --- | --- |
| 入学 | 回廊または各試験を初めて開く | ブラウザハッシュを主キーにする |
| 四科目の挑戦 | 対応する正式教室を開く | ブラウザ＋イベント名を複合主キーにする |
| 四科目の合格 | 既存の正式な保存記録が `passed: true` になった | 同上 |
| 卒業試験の挑戦 | 四科目修了後に正式な卒業試験ページを開く | 同上 |
| 卒業 | 既存の正式な卒業記録が `graduated: true` になった | 同上 |

合格イベントはサーバー側でも対応する挑戦イベントを補います。卒業試験へ進めるのは四科目修了後だけなので、卒業試験の挑戦・卒業は四科目の合格も補完します。通信が失敗してもゲームは進み、オンライン復帰または次回表示時に現在の保存記録を再照合します。

同じブラウザの更新、再挑戦、再合格、卒業画面の再表示では人数は増えません。端末のサイトデータを削除した場合、別ブラウザとして数え直されるため、実人数ではなく匿名ブラウザ単位の推計です。統計開始前の人数を推測して投入していません。統計開始前に遊んだブラウザが公開後に再訪した場合は、その再訪時点から一人として記録されます。

## 送信しないもの

氏名、入力した解答、自由メモ、各装置の操作履歴は送信しません。記録要求は、ランダムなブラウザIDとイベント名だけです。IPアドレスはEdge Function内でHMAC化し、レート制限用の短期バケットだけに使います。48時間を過ぎたバケットは次の記録要求時に削除し、生のIPアドレスはテーブルへ保存しません。

## セキュリティと大量送信対策

- ブラウザにSupabaseの公開鍵・秘密鍵・管理鍵を置かない。
- テーブルはすべてRLSを有効化し、`anon` と `authenticated` のDML権限を剥奪。拒否ポリシーも設定。
- RPCは `service_role` だけが実行でき、Edge Functionからのみ呼ぶ。
- 許可Originは正式公開元。ローカル検証用に `localhost` と `127.0.0.1` も許可。
- 同一IPハッシュからの要求は5分120回、新規ブラウザ登録は1時間25件まで。
- 本文は4 KiBまで。イベント名は定義済みの11種類以外を拒否。

ログインを要求しない公開統計なので、分散した送信元による意図的な改ざんを完全には防げません。今回の対策は、単純な再送、ページ更新、同一回線からの大量生成を抑えるものです。

## 表示と障害時

表示する割合は、各科目では `合格者 ÷ 挑戦者`、総合卒業率では `卒業者 ÷ 入学者` です。分母が0件なら `0.0%` と表示します。取得できない場合は数字を表示せず、「現在、学院運営記録を取得できません」と再読込ボタンを表示します。統計APIの失敗は合格判定、保存、卒業演出へ伝播しません。

- `research/graduation-release/test_browser.cjs`：統計通信を模擬応答へ差し替え、既存四科目と卒業試験の通し確認で本番統計を汚さない。

## 公開後の確認

ゲームの設定を開き、「学院の設定」を5回続けて操作すると統計を閲覧できます。データベースの詳細確認は、Supabase Dashboardでプロジェクト `jyxdjhrcowdijwzgqtyl` のTable EditorまたはEdge Functionログを開きます。行データを直接公開するビューはありません。

Supabaseが停止・障害状態なら記録簿は取得不能表示になりますが、ゲームは通常どおり遊べます。復旧後、ブラウザ内の既存進行から未送信イベントを再照合します。
