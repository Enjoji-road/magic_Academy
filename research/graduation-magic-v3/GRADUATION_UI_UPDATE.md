# 『手を離した、その先に』卒業演出・X共有の改修

日付：2026-10-22。改修元：`4e2a7c3f407679ce68bf5704ddafd7b3b99f8b0f`。

## 今回の変更

制作者の「難易度は適切。ただしスクロールしないと合格が分からない」という感想を受け、初めて光を残せた瞬間に、現在の画面位置に関係なく卒業を祝福するよう変更した。

魔法法則・余韻の受け渡し・支えの計算・合格条件・四再考察・魔力量・保存形式・保存キーは変更していない。`magic-model.js` は改修元とバイト単位で同一である。正式四科目と正式な入口ページも変更していない。

## 演出の流れ

1. 既存の `checkGraduation()` が、従来の `M.isClosed(...)` と未卒業フラグで初回の成功を検出する。
2. その時点で既に描画されている、完成した回廊のSVGを表示し、「手を離しても、光は残っています。」と約0.9秒確認させる。コピー元は実際に成功した状態の描画であり、演出側で正解を作らない。
3. 画面全体が約1.1秒で暗転する。
4. 回廊の先輩の三灯と新しい一灯を描いた卒業画面へ切り替え、約0.55秒で明るくする。
5. 中央に指定の二文を表示する。

> 卒業おめでとうございます
>
> あなたの灯した光が、次の生徒を迎えます。

全画面のネイティブ`dialog`を使用するため、スクロール位置や観測の集中表示より上に出る。演出中は研究画面へ入力できず、二重起動を受け付けない。途中のEsc操作でも、遅れて別の演出が起動することはない。

OSの `prefers-reduced-motion` または試作の「動きを減らす」が有効なら、光の確認後にフェードなしで卒業画面へ切り替える。合格の認識をアニメーションの有無に依存させない。

## 戻る・再表示・記録

- 「試験室に戻る」は画面を閉じるだけ。完成した魔法、魔力、メモ、観測記録に書き込まない。集中表示も保持する。
- 研究画面の操作台に「卒業画面をもう一度見る」を追加。卒業記録があれば、作り直しや再判定をせず表示できる。
- ページの再読込では自動再生しない。既存の `graduated` を過去の記録としてそのまま使用する。
- 魔法を組み直して現在の光が消えても、卒業記録は残る。
- 「この場所を最初に戻す」も、現在の装置だけをリセットして卒業記録を残すよう整理した。明示的に確認して行う「この試作の記録をすべて消す」では、従来どおり卒業記録も消える。

演出を見たかどうかの追加保存フラグは設けていない。新たな正解判定もない。

## X共有

`graduation-screen.js` 冒頭に、変更しやすい `SHARE_TEXT` と `SHARE_URL` をまとめた。投稿文は依頼文どおりで、解法や法則を含まない。

```text
🪄 魔法学校を卒業しました！🎓

四つの魔法を学び、最後の卒業試験にも合格しました。

あなたも魔法学校に入学してみませんか？
```

共有先は正式入口 `https://enjoji-road.github.io/magic_Academy/`。研究試作URLは送らない。

Xの公式投稿インテント `https://x.com/intent/tweet` に、`URLSearchParams`で `text` と `url` を渡す。日本語・絵文字・改行・URLはUTF-8のクエリとしてエンコードされる。通常のリンクを `target="_blank"` と `rel="noopener noreferrer"` で開き、自動投稿や外部SDKの読込は行わない。Xのタブを閉じても卒業画面は開いたままで、保存データは変化しない。

参照：X公式 [Web Intents](https://docs.x.com/x-for-websites/web-intents/overview)、[X Publish](https://publish.x.com/)。

## ブラウザ確認

Chromium 153で、追加の48項目と、従来の54項目の操作回帰を確認した。

| 依頼された確認 | 結果 |
|---|---|
| 正解時の自動発動／正解前に出ない | 通常の操作で確認。別の採点器は使用していない |
| 光が残った確認の後に暗転 | 実測：約900msの確認後、約1100msの暗転 |
| スクロール位置に関係なく表示 | ページ下部へ移動した状態から、画面全体に表示 |
| スマホのメッセージと操作 | 320×568、390×844、横向き844×390で、文章と両ボタンがスクロール不要で表示 |
| Xの文章・URL | 新規タブへの要求を捕捉し、復号後の日本語・絵文字・改行・正式入口URLが完全一致 |
| Xタブを閉じた後 | 卒業画面と保存文字列が変わらないことを確認 |
| 試験室へ戻る | 完成状態と保存文字列が変わらず、再観測できる |
| 任意再表示 | 魔法を再作成せず表示。現在の光がない場合も過去の記録から表示 |
| 再読込・履歴保持 | 卒業記録を保持し、強制再生しない |
| 動きを減らす | OS設定と試作内設定の両方で、フェードなしの卒業表示を確認 |
| 演出の多重起動 | 再起動要求を拒否。演出中のEscで中断しない |
| 正式科目と保存 | 既存110ファイルのハッシュ、四科目の正答受理、既存保存値の番兵チェックが通過 |

Xの検証では、外部遷移を捕捉して送信先と下書き引数を確認した。Xへログインして投稿確定するテストは行っていない。実機iOSのXアプリへの引き継ぎは未確認である。
