# 『魔法学校』完成版への統合

2026-10-22。制作者が実際に確認した第3次試作『手を離した、その先に』を、正式な四元素の回廊と四教室へ統合した版です。この文書には具体的な解法を記載していません。検証コード・モデルの中身にはネタバレがあります。

**[魔法学校を開く](https://enjoji-road.github.io/magic_Academy/)**

## 遊べる範囲

四科目を自由な順に受験し、四科目修了後に回廊から卒業試験へ進めます。再考察の扉は実際の各教室へつながり、装置のそばの「術の余韻を観測する」で続けられます。修了前の再考察も可能です。

通常の装置と余韻は操作対象を分けています。「装置へ使う」は、そのページの既存の操作へ渡します。「余韻へ触れる」は卒業用の状態だけを変えます。風の観測には同じ織布のモデルを使い、土では現在の石の配置を読み取ります。卒業用画面に九石の完成解や封印瓶の内部水量を表示する処理はありません。

最後の手を離して灯りが残ると、約0.9秒の確認、約1.1秒の暗転、卒業画面という流れになります。動きを減らす設定では暗転を省きます。通常の観測へ戻る、卒業画面を再表示する、Xの投稿画面を開く操作ができます。投稿の確定は本人が行います。

四科目の物理モデル、採点、解答、既存の保存キーは維持しています。操作JSの差分は、案内文と風の効果音OFFへの追従だけであることを元ソースとの比較で検証します。土の操作JSは変更していません。

研究試作のHTML・CSS・JS・魔法モデル・卒業演出は残しています。過去の研究時の「採用保留」は当時の評価です。今回は制作者の実プレイと完成版への統合依頼を受け、難易度を変更せず採用しています。

## 保存と復元

- 正式な卒業用キー：`magic-academy-graduation-v1`。
- 通常四科目、各科目の自由メモ、研究用試作のキーは移行・削除しません。
- 各教室は自分の余韻だけを更新します。別ウィンドウの古い状態で他教室やメモを上書きしないようにしています。
- 過去の卒業記録と現在の魔法状態を分けます。組み直しや局所リセットで光が消えても、卒業記録は残ります。
- 再読み込みだけで卒業演出を再生しません。明示した「卒業試験の記録を消す」だけが卒業用の記録を初期化します。
- 保存が利用できない場合は画面で通知します。四科目の合格確認には同じブラウザに保存された記録が必要です。

## 検証

`model-verification.json` は独立した固定点の全列挙と元ソース比較の結果です。14,641状態が研究時の独立Python検証と同じ結果になり、625通りの最終構成、作成順24通り、誤操作からの復帰を確認しています。通常四科目の正答受理も再確認しています。

`browser-verification.json` はChromiumによる通し確認です。四科目を実際の操作・解答フォームで合格し、修了前の再考察、実際の四教室への再訪、最後の魔法、卒業演出、X投稿インテントの別ウィンドウ、保存・再表示まで確認します。Xは要求URLと下書きを検証するために通信を捕捉し、実投稿は行いません。

320×568、390×844、768×1024、844×390、1280×900で卒業メッセージと操作を確認します。動きを減らす設定も含みます。iPhone・Android実機やSafariでの確認はこの自動検証には含まれません。

```bash
node research/graduation-release/verify_release.cjs
BROWSER_EXECUTABLE=/path/to/chromium node research/graduation-release/test_browser.cjs
```

ブラウザ検証にはNode.js、Playwright、Chromiumが必要です。HTTPサーバーはスクリプトが起動します。任意の `JAPANESE_FONT_DIR` は検証ホストのフォント用で、ゲーム本体は外部フォントを読み込みません。画像の出力先は `EVIDENCE_DIR` で指定できます。

## 残している作問上の性質

制作者が確認した難易度を維持しています。再訪履歴や魔法使用回数を合否に使わず、現在の魔法状態で判断します。そのため、回廊の実験から理解したプレイヤーが再訪を省ける性質も維持しています。数理的一意性と、人間がひらめくかどうかは別です。新たに他の初見プレイヤーでの面白さを証明したという意味ではありません。

## 卒業画面の再表示の修正（2026-10-22）

回廊の再表示ボタンに付けた `hidden` が、ボタンの `display` 指定で上書きされる不具合を修正しました。初期HTMLでも非表示・無効にし、CSSでも非表示を保ちます。クリック時と画面の読込完了時にも、保存済みの卒業記録を確認します。

初期状態、四科目合格のみの状態、卒業記録を明示的に消した状態では再表示できません。正規の卒業後は、光を組み直した後や再読み込み後も再表示できます。四科目の記録と過去の正当な卒業記録を、今回の修正で消すことはありません。

## 回廊の灯りと最終試験の入口の修正（2026-10-22）

「回廊の灯りを近くで見る」が最終試験と同じ操作画面を開いていたため、灯りだけを見る専用の観察窓へ変更しました。これまでの灯りの観測内容と保守記録は残し、魔法操作・最終課題・教室移動は表示しません。観察窓は保存データを書き換えません。

最終試験を開く共通処理で四科目修了を確認します。URLのハッシュ、直接の `graduation.html`、古い親画面からの埋め込みでも迂回できません。直接URLの試験内容は確認前に非表示とし、未修了なら回廊へ戻します。別タブで必要な合格記録が消えた場合も、未卒業の試験画面を閉じます。

各教室の「術の余韻」は、従来どおり修了前から観測できます。その画面には各教室のタイトルを表示します。正当に獲得した卒業記録は維持し、通常四科目の記録を後から消しても再表示できます。

ブラウザ検証には、0・1・2・3科目合格での各入口、四科目合格後の正式な入室、卒業済みの再表示、観察だけでは保存が変わらないこと、既存の灯りの手がかり、X共有の `#road謎` も含めています。
